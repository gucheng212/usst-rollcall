# 上理畅课助手 · USST Rollcall

上海理工大学「一网畅学」（`1906.usst.edu.cn`）的第三方网页客户端。装在自己电脑上跑一个小服务，
用浏览器就能看签到、查考勤、看课表、盯作业，不用一直开着畅课网页。

> **非官方**。本项目与上海理工大学、畅课（WisdomGarden/爱学医）无任何隶属关系，
> 只是把学校公开的网页接口用更方便的方式呈现出来。请自己判断使用风险。

## 它适合什么场景

- 上课时手机弹了签到通知，但你在电脑前做别的事，想让电脑替你盯着
- 想知道这学期到底缺了几次、请了几次假，出勤率是多少
- 想有个能一眼看完本周课表的地方，而不是每次翻畅课
- 想看还有哪些作业没交、还剩几天

它就是把这些事放在一个本地网页上，**不往任何第三方服务器发数据**。

## 它能做什么、不能做什么

| 功能 | 状态 | 说明 |
|---|---|---|
| 自动发现进行中的签到 | ✅ | 每 5–120 秒巡检一次，发现就弹提示 |
| 数字签到自动提交 | ✅ | 签到码由平台接口直接下发 |
| 雷达签到自动提交 | ✅ | 需要你事先保存教室坐标 |
| 二维码签到自动提交 | ❌ | 二维码内容只印在老师投屏的图上，接口不给，程序只做到"秒级发现 + 你把链接粘进来立刻提交" |
| 签到记录与出勤统计 | ✅ | 已签到 / 请假 / 缺勤 / 未知四态，按课程、类型、时间筛选 |
| 课表 | ✅ | 只显示当前活跃学期（平台接口不返回教室） |
| 作业清单与截止提醒 | ✅ | 只读，**不会替你交作业** |
| 登录态持久化 | ✅ | 重启服务不用重新登录 |
| 多账号/多人协助 | ❌ | 一次只服务一个账号（本机 `127.0.0.1`） |

**关于「自动签到」的态度**：默认全关，必须你自己打开。它能覆盖的只是"人到了但没看手机"这一种情况，
**不能替代到场**——雷达签到有距离校验、数字签到有出勤人数、老师端能看到提交时间。用不用、怎么用，你自己判断。

只需要一样东西：

| 依赖 | 版本 | 说明 |
|---|---|---|
| [Node.js](https://nodejs.org/zh-cn) | 20 或更高 | 推荐 22 LTS；Windows 装 `node.exe` 就行，Linux/macOS 用包管理器 |

**不需要** `npm install`：本项目零第三方依赖，也不联网下载任何包。

检查一下：

```bash
node -v      # 应输出 v20.x / v22.x / v24.x
```

## 快速开始

1. 下载仓库（`Code → Download ZIP`）或 `git clone`
2. 启动服务

   **Windows**：双击仓库里的 `启动.cmd`

   或者任意系统手动启动：

   ```bash
   cd usst-rollcall
   node server/index.mjs
   ```

3. 浏览器打开 <http://127.0.0.1:8619>

看到登录页就说明起来了。想换端口：`set PORT=8700`（Windows）或 `PORT=8700 node server/index.mjs`。

> 关掉那个黑窗口服务就停了。想让它开机自启，见 [常见问题](#常见问题)。

## 第一次登录

| 输入框 | 填什么 |
|---|---|
| 学号 | 你的学号（统一身份认证账号） |
| 密码 | 统一身份认证密码 |

- **密码忘了**：上理初始密码一般是「身份证后 6 位 + `usst`」（末位 x 写小写），留学生是「学号 + `usst`」。
  不行就到 [信息门户](https://myportal.usst.edu.cn) 重置，或联系信息办 021-55270595。
- **验证码**：正常登录**没有验证码这一栏**。上理的认证系统绝大多数时候不要求验证码；
  万一平台真的要求了（换网络、异常登录时偶发），登录界面会自动多出验证码输入框，填完再点登录即可。
- **密码去哪了**：只用来构造一次登录请求，换回会话 Cookie 后就丢掉了，**不写文件、不进日志**。
- 登录成功后右上角显示你的名字，关掉浏览器再打开也不用重新登录（除非 Cookie 过期或你在别处退出）。

## 界面导览

### 签到

上半部分是「正在进行」的签到卡片。每张卡片告诉你：哪门课、哪种类型、什么时候截止、已到多少人。

- **数字签到**：签到码已经自动填好，点「提交数字签到」即可（开了自动签到时连点都不用点）
- **二维码签到**：需要你把扫码得到的链接粘进输入框，点「立刻提交」
- **雷达签到**：设置里填好坐标后，点「用已保存的位置签到」

下半部分是「手动二维码签到」，用来补交你刚从手机上扫到的码。整条链接粘进去会自动识别。
点右上角「立即检查」可以不管巡检间隔马上查一次。

### 记录

所有历史签到，可按课程、状态（已签到/请假/缺勤）、类型（数字/二维码/雷达）、时间范围筛选。
顶部一行是汇总：总条数、出勤率、各状态计数、按类型分布。

出勤率算法：`（已签到 + 请假）/ 总数`，未知状态不计入分母。

### 课表

当前学期的周视图，周一到周日 7 列。只显示**当前活跃学期**的课，往届课程不会混进来。
平台接口不返回教室信息，所以这里留空是正常的。

### 作业

进行中的作业按截止时间排序，24 小时内会标红；已截止的单独一组。点开能看到作业详情和评分标准。
**只读，不会替你提交**。

### 设置

见下一节。

### 日志

运行日志（最近 300 条）。密码、Cookie、Token 会被自动替换成 `***`。出问题时先来这里看。

## 设置项说明

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用自动签到 | 关 | 总开关。关着的时候只巡检、只提醒，不提交 |
| 数字签到 | 开 | 勾选后自动交数字码 |
| 二维码签到 | 关 | 开了也没用（拿不到码），只会提醒你 |
| 雷达签到 | 关 | 需要先填下面两个坐标 |
| 巡检间隔 | 20 秒 | 5–120 秒。想抢秒级窗口就调到 5–10 秒，但别低于 5 秒 |
| 等出勤人数再提交 | 开 | 数字签到先等一等，避免"第 1 个交"太显眼 |
| 最低比例 / 最少人数 | 60% / 8 人 | 两个条件满足任一就提交 |
| 最长等待 | 90 秒 | 等超时就放弃这次，不再补交 |
| 检测窗口 | 空 | 空 = 全天候。格式 `07:30-12:00@1,2,3,4,5`（1=周一，7=周日），可写多行 |
| 雷达坐标 | 空 | 上课教室的纬度/经度。点「用当前浏览器的位置」可以自动取（要在教室里取才准） |
| 二维码占位数据实验 | 关 | 拿不到码时用假数据试提交一次，用来验证平台是否校验二维码内容。平时不用开 |
| 开启桌面通知 | — | 点一下授权后，新签到会弹系统通知。二维码窗口只有几分钟，建议开 |

建议配置：**检测窗口**按你的课表填（比如 `07:50-12:00@1,2,3,4,5` + `12:50-18:00@1,2,3,4,5`），
这样它只在上课时段工作，其它时间不打扰你、也不给学校服务器添压力。

## 在手机或平板上用

服务跑在电脑上，手机同一个 Wi-Fi 也能访问，两种办法：

**A. 用 USB 转发（推荐，只有你的手机能访问）**

```bash
adb reverse tcp:8619 tcp:8619
```

然后手机浏览器打开 <http://127.0.0.1:8619>。

**B. 监听局域网**

```bash
# Windows
set HOST=0.0.0.0 && node server/index.mjs
# macOS / Linux
HOST=0.0.0.0 node server/index.mjs
```

然后用电脑的局域网 IP 访问，例如 <http://192.168.1.20:8619>。

> ⚠️ 方式 B 会让**同一 Wi-Fi 下的其他人**也能打开这个页面，并操作用你的账号。教室/宿舍网络慎用，
> 用完记得改回默认（只监听 `127.0.0.1`）。页面没有账号密码，谁能打开谁就能用你的身份签到。

## 命令行工具

服务之外还有几个脚本，都在仓库根目录跑：

```bash
# 盯住接下来的签到（只观察，不提交）
node scripts/watch-live.mjs --minutes 60

# 盯住并真的提交（数字/雷达），打印原始请求与响应
node scripts/watch-live.mjs --try --minutes 90

# 对运行中的服务打一圈接口，14 项自检
node scripts/selfcheck.mjs

# 跑全部单元测试（59 项）
node scripts/test-all.mjs
```

`watch-live.mjs` 的日志会追加到 `.data/live-watch.log`，适合"下课回来看看到底发生了什么"。

## 数据存在哪里，怎么彻底删掉

所有运行时数据都在仓库的 `.data/` 目录（已被 `.gitignore` 忽略，不会误传到 GitHub）：

| 文件 | 内容 |
|---|---|
| `.data/persist/session.json` | 会话 Cookie + 你的昵称/学号/院系，用于免登录 |
| `.data/persist/settings.json` | 你在设置页填的东西 |
| `.data/persist/device.json` | 一个随机 UUID，畅课作答接口要求的设备标识（只生成一次） |
| `.data/persist/cache/` | 课程、课表、签到记录的本地缓存 |
| `.data/app.log` | 运行日志（已脱敏） |

- **退出登录**：页面右上角「退出」，会同时删掉 `session.json` 里的凭据
- **彻底清空**：停掉服务，删掉整个 `.data/` 目录，下次启动等于全新安装
- **换账号**：先退出登录，再登另一个学号

## 常见问题

**Q：登录一直失败 / 提示要验证码？**
先确认账号密码能在 <https://1906.usst.edu.cn> 网页里登进去。能登进去但这里不行的话，
多半是平台要求了验证码或改了登录流程——登录界面会自动出现验证码框，填一次；还不行就看「日志」页的具体报错。

**Q：数字签到显示「平台返回 Not Found」？**
这句的意思是**这次签到当前不可作答**（已经结束、或者还没到时间），不是程序坏了。
平台对已结束的签到一律这么回，所以没法事后补交。

**Q：二维码签到为什么不自动交？**
二维码里那串数据只印在老师投屏的图上，平台不通过任何接口发给学生，空着提交会被服务器直接拒（`no data`）。
所以它的自动上限是：秒级发现 + 你把扫到的链接粘进来一键提交。

**Q：课表里没有教室？**
平台接口本身不返回教室字段，所有客户端都拿不到。

**Q：出勤率怎么算的？**
`（已签到 + 请假）/ 总条数`。请假算进"已出勤"是因为它不影响考核；未知状态不进分母。

**Q：端口 8619 被占用？**
`set PORT=8700` 换个端口，浏览器也跟着打开新端口。

**Q：想让它开机自启？**
Windows 可以在「任务计划程序」里加一条"登录时运行 `启动.cmd`"；macOS 用 `launchd`；Linux 用 `systemd`。
注意服务必须在你登录状态下跑（它要读写 `.data/`）。

**Q：会不会把我的账号密码传到别的地方？**
不会。所有请求都从你的机器直连 `1906.usst.edu.cn` 和 `ids6.usst.edu.cn`，没有任何中转服务器，代码全在这里可以自己看。

## 隐私与安全

**这个项目怎么处理你的数据**

- 密码只用于构造一次登录 POST，用完即丢，**不写文件、不进日志**（日志里 `password`/`cookie`/`token` 字段自动打码）
- 持久化的只有会话 Cookie 和昵称/学号/院系，全部在你自己机器的 `.data/` 里
- 没有任何统计、没有上报、没有第三方 SDK，前端不引用任何外部 CDN（断网可用）
- 写操作会校验 `Origin`，防止同机其它网页偷着调你的接口
- 接口请求全局限速（最小间隔 220ms）并带退避重试，避免给学校服务器造成压力

**如果你要 fork 或提 PR**

- **别提交 `.data/` 目录**（已 `.gitignore`）——里面的 Cookie 等价于你的登录态
- 别把日志、截图里的学号、姓名、Cookie 贴进 issue
- 测试和文档里请用中性示例（`123456`、`学号` 之类），不要用真实数据

**技术选型**：Node.js 零依赖（`http` + `fetch`）+ 原生前端，没有构建步骤。
之所以不用 Flutter/Dart 复刻同类项目，是因为这份代码要在没有 SDK 的机器上双击就能跑。

**目录**

```

├─ server/
│  ├─ index.mjs        入口：恢复会话 → 监听 8619 → 已登录则启动巡检
│  ├─ config.mjs       站点地址、UA、接口版本、超时/限速（可用环境变量覆盖）
│  ├─ app.mjs          HTTP 路由 + SSE 推送 + 静态资源
│  ├─ cas.mjs          上理登录链路（1906 → Keycloak → ehall → 金智 IDS6）
│  ├─ tron.mjs         畅课接口封装（课程/课表/签到/作业/作答）
│  ├─ endpoints.mjs    URL 构造、签到类型识别、出勤四态归一、作答候选路由
│  ├─ monitor.mjs      巡检与自动作答
│  ├─ session.mjs      会话管理与持久化
│  ├─ store.mjs        `.data/` 读写
│  ├─ httpx.mjs        CookieJar + 限速 + 重定向跟随
│  ├─ logger.mjs       脱敏日志
│  └─ httpserver.mjs   JSON 解析与响应封装
├─ web/                单页前端（index.html / app.js / app.css）
├─ test/               单元测试
└─ scripts/            自检、盯梢、接口探针
```

**上理特有的坑**（都已在代码里处理）

| 现象 | 处理 |
|---|---|
| 登录不是 OAuth，而是 `1906 → Keycloak(CAS client) → ehall 适配器 → 金智 IDS6`，共 5 跳 | `cas.mjs` 逐跳跟随，判据是 `GET /api/profile` 返回 200，而不是"拿到 Cookie" |
| 上理的 CAS **没有** `pwdEncryptSalt`，密码是明文表单提交 | 直接表单提交，不做 AES |
| 签到列表主键叫 `rollcall_id`，不是 `id` | `normalizeRollcall()` 统一成 `id` |
| `/api/rollcall/{id}` 会 500 | 用 `/api/rollcall/{id}/student_rollcalls` 代替 |
| `/api/timetable_rollcalls` 多课程必须 `course_ids[]=1&course_ids[]=2`，逗号拼串会 500 | `endpoints.timetableRollcalls()` 逐项生成 |
| 课程列表不带课表，要逐门 `?fields=…timetables…` 且没有教室 | `courseTimetable()` 并发拉取，30 分钟缓存 |
| 方法不对不返回 405，而是 500 HTML；404 有两种含义 | 中文「未找到资源」= 路由不存在；英文 `Not Found` = 当前不可作答 |
| `on_call` 是 `on_call_absence` 的前缀 | 出勤归一必须先判缺勤、再判请假、最后判已签到 |

**接口清单**（全部走 `1906.usst.edu.cn`）

| 用途 | 接口 |
|---|---|
| 用户信息 | `GET /api/profile` |
| 课程列表 | `GET /api/my-courses?per_page=1000` |
| 学期 | `GET /api/semesters` |
| 课表 | `GET /api/courses/{id}?fields=id,name,timetables,classroom_schedule` |
| 签到历史 | `GET /api/course/{cid}/student/{sid}/rollcalls?page=1&page_size=100` |
| 签到详情/签到码 | `GET /api/rollcall/{id}/student_rollcalls` |
| 进行中的签到 | `GET /api/radar/rollcalls` + `GET /api/timetable_rollcalls?course_ids[]=…` |
| 数字签到作答 | `PUT /api/rollcall/{id}/answer_number_rollcall`（`{deviceId, numberCode}`） |
| 二维码作答 | `PUT /api/rollcall/{id}/answer_qr_rollcall`（`{deviceId, data}`） |
| 雷达作答 | `PUT /api/rollcall/{id}/answer?api_version=1.76` |
| 待办 | `GET /api/todos` |
| 作业详情 | `GET /api/activities/{id}` |

作答请求要带 `x-session-id` 头（值取 `GET /api/captcha-code` 的响应头），与官方 App 一致。
平台改接口时，改 `server/endpoints.mjs` 的 `ANSWER_ROUTES` 即可。
